# Order System — C# / WPF / SQLite

**Order Management System** — учебное desktop-приложение для управления заказами, покупателями и товарами. Проект разработан на C# с использованием WPF, SQLite и архитектурного паттерна **MVVM (Model–View–ViewModel)**.

## 🛠 Технологии

- **C#** — основная логика приложения.
- **WPF** — создание графического интерфейса.
- **SQLite** — реляционная база данных.
- **SQL** — запросы для работы с данными.
- **MVVM** — разделение интерфейса, состояния представления и логики приложения.
- **CommunityToolkit.Mvvm** — поддержка MVVM, наблюдаемых свойств и команд.

## 📋 Основные возможности

- Управление покупателями и товарами.
- Создание и сохранение заказов.
- Добавление и удаление позиций заказа.
- Выбор покупателя для заказа.
- Указание количества товаров.
- Проверка доступного количества товара на складе.
- Автоматическое обновление складских остатков при добавлении и удалении позиций заказа.
- Расчёт общей стоимости заказа.
- Просмотр списка заказов с информацией о товарах и итоговой стоимости.
- Сохранение данных в SQLite.

## 🏗 Архитектура проекта

В проекте используется паттерн **MVVM**, который разделяет приложение на несколько уровней ответственности.

### View

Представления, созданные с помощью WPF и XAML. Отвечают за отображение данных и взаимодействие с пользователем.

### ViewModel

Классы, связывающие представления с логикой приложения. Управляют состоянием интерфейса, предоставляют данные для отображения и реализуют команды для выполнения действий пользователя.

Для связи с интерфейсом используются привязки данных (*Data Binding*), команды (*Commands*) и наблюдаемые свойства.

### Model

Модели предметной области, представляющие основные сущности приложения: покупателей, товары, заказы и позиции заказов.

### Data

Классы доступа к данным, отвечающие за выполнение SQL-запросов, получение записей, добавление и изменение данных в SQLite.

### Services

Сервисы, предназначенные для организации общей логики приложения и взаимодействия между отдельными компонентами, например для хранения общих коллекций и управления окнами.

## 🗄 Структура данных

| Сущность | Описание |
|---|---|
| `Customer` | Информация о покупателе |
| `Product` | Информация о товаре и его складских остатках |
| `Order` | Заказ покупателя |
| `OrderItem` | Позиция заказа, содержащая товар, количество и связь с заказом |

Связи между сущностями:

- Один покупатель может иметь несколько заказов.
- Один заказ может содержать несколько позиций.
- Каждая позиция заказа связана с определённым товаром.

## ⚙️ Работа с базой данных

Для хранения данных используется SQLite. Подключение к базе данных организовано через класс `Database` и свойство `ConnectionString`.

Доступ к данным вынесен в отдельные классы, чтобы отделить SQL-запросы от кода представлений и ViewModel.

При создании записей используется SQL-запрос `last_insert_rowid()` для получения идентификатора последней добавленной записи.

При добавлении товара в заказ приложение проверяет доступный складской остаток, сохраняет позицию заказа и обновляет количество товара в таблице `Products`.

## 🚀 Запуск проекта

   ```bash
   git clone https://github.com/everidiy/OrderSystem_BY_CSHARP_SQL
   ```

2. Откройте решение проекта в Visual Studio.

3. Восстановите NuGet-зависимости, если это потребуется.

4. Убедитесь, что строка подключения к SQLite указывает на корректное расположение файла базы данных.

5. Соберите и запустите приложение.

## 🎯 Цель проекта

Проект создан для практического изучения разработки desktop-приложений на C#, работы с WPF и SQLite, написания SQL-запросов и применения архитектурного паттерна MVVM.

В процессе разработки отрабатываются разделение ответственности между компонентами приложения, привязка данных, использование команд, организация доступа к базе данных и взаимодействие между моделями, представлениями и ViewModel.
