# Order System — C# & SQLite

**Order Management System** — учебное desktop-приложение для управления заказами, покупателями и товарами. Проект разработан на C# с использованием WPF для графического интерфейса и SQLite для хранения данных.

## 🛠 Технологии

- **C#** — основная логика приложения.
- **WPF** — графический пользовательский интерфейс.
- **SQLite** — реляционная база данных.
- **SQL** — работа с данными и выполнение запросов.

## 📋 Основные возможности

- Управление покупателями и товарами.
- Работа с заказами и их позициями.
- Добавление товаров в заказ с указанием количества.
- Проверка доступного количества товара на складе.
- Автоматическое уменьшение складских остатков при добавлении товара в заказ.
- Сохранение данных в SQLite.

## 🗄 Структура данных

В приложении используются следующие основные сущности:

| Сущность | Описание |
|---|---|
| `Customer` | Информация о покупателе |
| `Product` | Информация о товаре и его складских остатках |
| `Order` | Заказ покупателя |
| `OrderItem` | Позиция заказа: товар, количество и связь с заказом |

Связи между сущностями:

- Один покупатель может иметь несколько заказов.
- Один заказ может содержать несколько позиций.
- Каждая позиция заказа связана с определённым товаром.

## ⚙️ Работа с базой данных

Для хранения данных используется SQLite. Подключение к базе данных организовано через класс `Database` и свойство `ConnectionString`.

При добавлении записи используется SQL-запрос с `last_insert_rowid()` для получения идентификатора созданной записи.

При добавлении товара в заказ приложение проверяет доступный остаток, сохраняет позицию заказа и обновляет количество товара в таблице `Products`.

## 🚀 Запуск проекта

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/everidiy/OrderSystem_BY_CSHARP_SQL.git
   ```

2. Откройте решение проекта в Visual Studio.

3. Восстановите необходимые зависимости, если это потребуется.

4. Убедитесь, что строка подключения к SQLite указывает на корректное расположение файла базы данных.

5. Соберите и запустите приложение.

Проект создан для практического изучения разработки приложений на C#, работы с WPF, SQL-запросами и реляционными базами данных.

В процессе разработки отрабатываются принципы взаимодействия графического интерфейса с логикой приложения, создание и сохранение записей, связи между сущностями и обновление данных в базе.
